# Routes

- `/` — `app/page.js` — Landing page with a large nightlife headline, three navigation choices, violet ray background, and featured event cards.
- `/events` — `app/events/page.js` — Events discovery page with navigation, featured-event carousel, category navigation, event grid, and filter drawer.
- `/clubbers` — `app/clubbers/page.js` — Social feed with sidebar and suggestion panel.
- `/groups` — `app/groups/page.js` — Placeholder route.
- `/settingsu` — `app/settingsu/page.js` — Profile editing screen.

All routes use `app/layout.js`.
