# Extractable Components

## EventNavbar

- Source: `components/events/EventNavbar.js`
- Category: layout
- Description: Events top navigation with SceneMates wordmark, search, location, and profile controls.
- Extractable props: none currently
- Hardcoded: labels, icon names, routes, and Tailwind styles

## SideRays

- Source: `components/effects/SideRays.js`
- Category: layout
- Description: Reusable animated WebGL white/violet ray background used on landing and events pages.
- Extractable props: origin, colors, speed, intensity, spread, tilt, saturation, blend, falloff, opacity
- Hardcoded: WebGL shaders and rendering behavior

## EventCard

- Source: `components/events/EventCard.js`
- Category: basic
- Description: Event discovery card with image, date, category, venue, time, price, and booking action.
- Extractable props: event
- Hardcoded: icon mapping, booking label, and Tailwind styles
